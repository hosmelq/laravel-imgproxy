# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## v3.0.0 - 2026-10-20

### Added

- Image-info URLs (imgproxy Pro) through `Imgproxy::infoBuilder()` and the `imgproxyInfo()` disk macro.
- Config for the arguments separator, source chunk size and filename, trusted signature, presets-only mode and option aliases.

### Changed

- **Breaking:** Require [`hosmelq/imgproxy` ^2.0](https://github.com/hosmelq/imgproxy-php/blob/main/CHANGELOG.md). The same builder calls may now produce different URLs; see its changelog for details.
- **Breaking:** `format()` no longer adds an extension. Pass `build(extension: 'webp')`, which the Storage macros now accept along with `encoding`.
- **Breaking:** Unknown `source_encoding` values, invalid custom IVs and invalid encryption keys throw.

### Fixed

- Encrypted sources are padded once. Rebuild encrypted URLs generated by earlier versions.

## v2.0.0 - 2026-09-23

- Require PHP 8.4 or newer.
- Support Laravel 12 and 13, and drop Laravel 11.
- Update the Pint, Rector, PHPStan, and Pest configuration.
- Rework the GitHub Actions workflows and add GitHub Actions security analysis.

## v1.0.0 - 2025-12-03

- Initial release.
